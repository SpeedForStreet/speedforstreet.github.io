# SpeedForStreet — GitHub Pages

1. Создай публичный репозиторий на GitHub.
2. Загрузи `index.html`, `style.css`, `script.js`.
3. Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
4. В `index.html` замени ссылки `#` у VK/TG/TT/IG на реальные страницы.

Сайт полностью статический и не требует сервера.
